# CyaCloud Downloads

Acesse o [site público de downloads](https://phgs-oficial.github.io/cyacloud-downloads/). Qualquer pessoa pode baixar os arquivos sem criar conta.

## Como funciona

- Os arquivos ficam somente no servidor, dentro de `/home/phgs/cyacloud`.
- O site no GitHub Pages publica apenas a página e o catálogo (nome, tamanho e endereço de download). Os arquivos não são enviados ao GitHub.
- O servidor entrega os downloads pela internet por meio de um Cloudflare Tunnel. O catálogo acompanha o endereço público ativo.

Mantenha o servidor e a conexão com a internet ligados para que os downloads fiquem disponíveis.
